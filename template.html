About the assumptions and sources

Theoretical percentages use anhydrous chemical composition (bisglycinate 14.1%, citrate 16%, oxide 60%). Actual ingredient grades can assay differently. Capsule sizes specify volume; this example converts volume to a powder-weight range using 0.6–1.0 g/mL. It does not include fillers or measure a specific product.

Capsule size and density reference. For formulas combining forms, read each medicinal ingredient; this single-form estimate cannot determine the blend. Always check serving instructions. No absorption or health outcome can be inferred from this calculation.
